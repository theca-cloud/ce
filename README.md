# Theca CE

The Community Edition of [Theca](https://git.pband.ch/theca/docs), a self-hosted cloud storage: the [core](https://git.pband.ch/theca/core) server and the [web](https://git.pband.ch/theca/web) app in one image, with what it takes to run it (a compose with Postgres and S3 storage, the setup, the WebDAV sync documentation).

**Status**: starting. Nothing to run here yet; meanwhile, `core`'s `try/` runs the server alone.
