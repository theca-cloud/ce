# Step 05: First release

Goal: the CE image `0.1.0` published, with its Gitea release: the `web` and `core` it holds, the changelog, and `docker-compose.yml` attached (naming `ce:0.1.0`), as `SELF-HOSTING.md` downloads it.

- `scripts/release.sh` on `dev`: the first release is `VERSION`'s `0.1.0` (no tag yet), the compose's tag already `0.1.0`, `CHANGELOG.md` from the commits.
- `dev`'s pipeline: the checks and the `0.1.0-rc` image; then `prod` (`git merge --no-ff dev`): the image `0.1.0`, `0.1`, `0`, `latest`, the tag and the release. First run of the compose's attachment (`release-ci.sh publish`).
- Checked after: the release's notes and asset, the image's labels, and `SELF-HOSTING.md`'s install from the attached compose.
- On the private registry, as every image until 1.0 (`ROADMAP.md`).
